# 🚚 Fleet Management System

A modern **Fleet Management System** designed to simplify fleet operations by providing vehicle tracking, driver management, trip monitoring, maintenance scheduling, and analytics through an intuitive dashboard.

---

## 📖 Overview

Managing a fleet manually can be time-consuming and inefficient. This project provides a centralized platform that helps organizations monitor vehicles, optimize operations, reduce maintenance costs, and improve overall fleet performance.

---

## ✨ Features

- 🚗 Vehicle Management
- 👨‍✈️ Driver Management
- 🛣️ Trip Monitoring
- 📍 GPS Location Tracking
- ⛽ Fuel Consumption Tracking
- 🔧 Vehicle Maintenance Scheduling
- 📊 Dashboard with Analytics
- 🔔 Maintenance Alerts & Notifications
- 📅 Trip History
- 📈 Performance Reports
- 🔒 Secure Authentication
- 📱 Responsive User Interface

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/Fleet-Management-System.git
```

### Navigate to the Project

```bash
cd Fleet-Management-System
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```
